# ChatGPT logo prompt

Copy everything below the line into ChatGPT (use **Create image** / DALL·E). Ask for a square app icon first, then a wordmark if you like the mark.

---

Design a premium app icon and logo for **Solo Scrum**, a calm local desktop Scrum board for a single developer. No accounts, no cloud — just one person moving stories across a board.

**Concept**
A refined app icon that reads as a tiny Kanban board, not a generic sprint or sticky-note cliché. The existing in-app mark is three vertical bars of increasing opacity inside a rounded square — like columns filling up as work ships. Evolve that idea into a polished brand mark.

**Composition (app icon)**
- Rounded-square macOS-style icon, 1:1, generous padding
- Soft frosted-glass tile (light, almost white) with a faint inner highlight
- Three rounded vertical columns / bars, left to right: short / mid / tall, or light / medium / solid
- Bars tinted with the product’s column colors: blue `#3B82F6` (backlog), amber `#F59E0B` (in progress), violet `#8B5CF6` (tested), with a hint of mint `#10B981` only as a tiny accent on the tallest bar (done) — do not use all four equally; prefer blue + ink as the heroes
- Subtle depth: glass, soft shadow, no hard skeuomorphism
- Optional tiny “SS” monogram is fine only if it stays secondary and elegant

**Wordmark (separate frame)**
- “Solo Scrum” in a tight modern grotesque, slightly condensed, letter-spacing like SF Pro Display
- Color: near-black `#12141A` on a pale cool gray `#F4F6FB`
- Place the icon mark to the left of the type, optically aligned
- Tagline optional and very small: “Local board for one developer”

**Style**
Apple-like, editorial, quiet luxury. Frosted glass, cool daylight, airy. Think Linear + Things + a well-made indie Mac utility. Matte, high-end, not playful, not corporate Agile clipart.

**Color palette**
- Background: `#F4F6FB`
- Ink: `#12141A`
- Muted: `#5D6472`
- Accent blue: `#3B82F6`
- Soft glow orbs (background only, very faint): powder blue, lilac, mint

**Deliver 4 images**
1. App icon, light glass, square, no text
2. App icon, slightly darker glass so it also works on a dark Dock
3. Horizontal lockup: icon + “Solo Scrum”
4. Simple monochrome (ink-only) version for a favicon / menu bar

**Do not include**
People, runners, stopwatches, clipboards, sticky notes, burndown charts, checklists overflowing with text, Jira-like logos, gradients that look like a SaaS startup from 2021, 3D clay, neon, mascots, or the word “Agile” on the artwork.

Make it look like a real shipped Mac app icon, not a concept collage.
